# 十年春风 Seedance 2.0 分镜规则 V4

用途：将《十年春风，与君归》剧本拆成 Seedance 2.0 可用的视频分镜提示词。

## 核心规格

- 每条视频：最长不超过15秒
- 画幅：9:16竖屏
- 相机设定：索尼FX3，全画幅，9:16竖屏
- 风格：严肃写实，写实仿真人，古装短剧，电影感
- 表演语言：普通话
- 字幕限制：视频中禁止出现任何字幕、标题字、说明字、屏幕文字叠加
- 音频限制：禁止背景音乐，仅保留角色语音、环境特效音、动作音效
- 人物面部质感：面部清晰真实，无反光、无油光；自然毛孔感明显，无磨皮涂抹感
- 每条视频时间轴：必须从 `00:00` 重新起算
- 每条视频可包含多个镜头，但不强行压缩剧情
- 如果一个场次超过15秒，拆成“视频1 / 共N条”“视频2 / 共N条”

## 每条视频必须包含

### 全局空间锚点

每条视频开头必须写：

1. 场景：地点、时间、环境状态
2. 光影：自然日光、烛光、夜景、逆光等
3. 人物站位：所有出场人物的位置、朝向、距离关系
4. 人物状态：站、坐、行走、回头、手持道具等
5. 道具位置：重要道具在哪里、由谁拿着、开口/正面朝向哪里
6. 声音环境：仅写环境音、人物语音、动作音效，不写背景音乐

人物站位必须具体，比如：

```text
人物：
@顾灵薇站在长街中央，面向镜头，双手捧着@鎏金锦盒，锦盒位于胸前偏下，盒口朝上并略微朝向自己的脸；
@苏明舒站在@顾灵薇右前方三步外，侧身面向@顾灵薇，手里捧着@糖炒栗子；
@贵女们站在@苏明舒身后两步，半围观状态；
@围观百姓分布在街道两侧，形成半圆围观。
```

## 镜头连贯规则

### 1. 上一镜头结果 = 下一镜头起点

连续镜头必须接得上，不能凭空变化。

示例：

```text
00:00-00:03 近景/固定：
画面：@顾灵薇双手打开@鎏金锦盒，盒口朝上，盒底机关槽露出。

00:03-00:06 特写/慢推：
画面：延续上一镜头，@鎏金锦盒仍在@顾灵薇胸前，盒口朝上，盒底机关槽弹开，金粉从盒内喷向@顾灵薇脸部。
```

### 2. 道具必须保持朝向一致

重要道具必须写清：

- 谁拿着
- 左手/右手/双手
- 道具在身体哪个位置
- 正面/开口/锋刃/文字朝向哪里
- 下一镜头是否延续同一方向

### 3. 关键动作必须写清因果链

所有关键动作必须写清：

```text
来源 → 方向 → 过程 → 结果
```

错误写法：

```text
@纸条贴上@顾灵薇额头。
```

正确写法：

```text
@纸条从@鎏金锦盒盒底机关槽弹出，沿着由下往上的弧线飞向@顾灵薇额头，啪地贴住，纸条文字清楚可见：「借来的福，不好拿。」
```

### 4. 人物移动必须写清路线

人物移动不能只写“走来”，要写：

- 从哪里来
- 走向哪里
- 经过谁
- 停在谁的哪个方向
- 距离大约几步

示例：

```text
@顾灵薇从@苏明舒身后左侧快步上前，越过@苏明舒半步，停在摊位正前方，右手抢先拿起@鎏金锦盒。
```

## 镜头设计细化规则

每个镜头段落尽量写清以下摄影信息：

- 镜头类型：特写 / 大特写 / 中景 / 全景等
- 机位角度：正面平拍、侧前方平拍、背后跟拍、仰拍15度、俯拍30度等
- 焦段与光圈：如 85mm定焦 F1.4、100mm微距 F2.8、24mm广角 F8
- 景深：极浅景深、浅景深、中等景深、大景深
- 运镜：固定、慢推、慢拉、跟拍、横摇、手持晃动等
- 光源：自然日光、侧逆光、小型柔光、点光源、轮廓光等
- 表演细节：咬牙、下颌线紧绷、手指收紧、眼神避让、瞳孔微缩、呼吸停顿等
- 道具质感：金属冷光、纸张纤维、木盒纹理、金粉颗粒、玉石半透光等

示例写法：

```text
00:03-00:06 大特写/正对道具平拍，100mm微距，F2.8，极浅景深，固定镜头：
画面：@顾灵薇右手指节收紧，@鎏金锦盒盒底机关槽弹开，细小铜簧在日光下反光；@纸条从机关槽内向上弹出，纸张边缘轻颤。
音效：[SFX: 机关咔哒，纸条弹出嗖声] @00:03
```

## 禁止项

- 禁止字幕、标题字、解释字、旁白字卡出现在画面里
- 禁止背景音乐、配乐、BGM
- 禁止卡通化、漫画化、夸张变形表演
- 禁止人物皮肤塑料感、磨皮感、油光反光
- 禁止重要道具在连续镜头中无故变换方向或持有人
- 禁止用一句“纸条贴上额头”跳过机关来源和飞行过程

## 输出格式

```text
═══════════════════════════════════════════
### [集数-场次] [日/夜] [内/外] [地点]（视频 X / 共 N 条）
═══════════════════════════════════════════

[全局空间锚点]
场景：@地点，时间，环境状态。
相机：索尼FX3，全画幅，9:16竖屏。
光影：光影方案。高画质，电影感，无水印，画面干净；人物面部清晰真实，无反光无油光，自然毛孔感，无涂抹感。
声音：无背景音乐，仅保留普通话角色语音、环境音、动作音效。
人物：逐一写清人物站位、朝向、距离关系、当前姿态。
道具/环境细节：逐一写清重要道具位置、持有人、朝向、状态。

[转场：硬切/闪黑/叠化] 仅跨场次需要

---

00:00-00:03 景别/运镜：
画面：动作描写。必须承接上一个状态。写清人物位置、身体动作、道具方向、情绪变化。
台词：(XS) @角色名（情绪）:「台词」
音效：[SFX: 描述] @XS

00:03-00:07 景别/运镜：
画面：继续承接上一镜头，写清动作来源、方向、过程、结果。
台词：无
音效：[SFX: 描述] @XS

---
```

## 自检清单

输出前逐条检查：

- 每条视频是否 ≤15秒
- 时间轴是否从 `00:00` 开始
- 每个镜头是否有明确景别和运镜
- 人物站位是否写清：位置、朝向、距离
- 重要道具是否写清：持有人、位置、朝向、状态
- 上一镜头结果是否成为下一镜头起点
- 关键动作是否包含：来源、方向、过程、结果
- 台词是否保留原文，不乱改
- @角色名、@重要道具 是否标注完整
- 画幅是否写明 `9:16竖屏`
- 是否写明索尼FX3、无字幕、无背景音乐
- 是否避免画面中出现任何字幕或说明字
- 是否写清人物面部无油光、无反光、自然毛孔感
